Privacy policy

Job Agent Bot is a personal tool used only by its owner. It has no other users.

Data accessed

With the owner's authorization, the tool accesses the owner's Gmail (to read job alerts and replies about job applications, send notifications to the owner and create draft emails), Google Sheets (to keep the application tracker) and Google Drive (to store generated CV files in a dedicated folder).

Web dashboard

The dashboard at ilcap5.github.io/jobscout reads and updates the owner's tracker sheet directly from the browser, with a short-lived Google access token. The page has no server: no data is sent to or stored by this website.

Profile setup

On the profile page the owner can upload a CV (PDF) and answer a questionnaire. The CV and the answers are sent, with the owner's Google sign-in, to a small API run by the owner on Cloudflare Workers, which forwards them to the Anthropic API to extract the profile. Nothing is stored by the API: the resulting profile is saved in the owner's Google Sheet.

How data is used

Data is used only to manage the owner's job applications. Job descriptions, the owner's CV and emails related to applications may be processed through the Anthropic API to analyse job posts and draft texts. Data is not sold, shared with third parties for other purposes, or used for advertising.

Storage and revocation

Data stays in the owner's Google account. Access can be revoked at any time from https://myaccount.google.com/permissions.
